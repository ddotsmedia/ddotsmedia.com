## Quick Start — Deploy in 10 minutes

### Step 1: Bootstrap VPS (5 min, one-time)
```bash
ssh root@187.127.185.239 'bash -s' < scripts/bootstrap-vps.sh
```

**This sets up:**
- Docker engine + Docker network
- PostgreSQL container with persistent volume
- Nginx reverse proxy with HTTP→HTTPS redirect
- Let's Encrypt SSL certificate
- `.env.prod` with random secrets
- `/opt/ddotsmedia` directory structure

### Step 2: Configure GitHub Secrets (2 min)
Go to: https://github.com/ddotsmedia/ddotsmedia.com/settings/secrets/actions

Add 3 secrets:
```
VPS_HOST = 187.127.185.239
VPS_USER = root
VPS_SSH_KEY = <your private key from ~/.ssh/id_rsa>
```

**Need an SSH key?**
```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_rsa -N ""
ssh-copy-id -i ~/.ssh/id_rsa.pub root@187.127.185.239
cat ~/.ssh/id_rsa  # Copy this as VPS_SSH_KEY
```

### Step 3: Deploy (3 min)
**Option A:** Push to main branch
```bash
git push origin main
# GitHub Actions runs tests → builds → waits for approval
# Go to Actions tab → "Review deployments" → Approve
```

**Option B:** Manual trigger
- Go to: https://github.com/ddotsmedia/ddotsmedia.com/actions/workflows/deploy.yml
- Click "Run workflow" → "Run workflow"
- Wait for approval prompt → Click "Approve and deploy"

### Step 4: Verify (1 min)
```bash
# Check it's live
curl -I https://ddotsmedia.com
# Should return: HTTP/2 200

# Open in browser
https://ddotsmedia.com       # Homepage
https://ddotsmedia.com/admin  # Admin panel (login with OWNER_EMAIL/OWNER_PASSWORD)
```

## Troubleshooting

### Bootstrap fails: "Database backup failed"
- Non-fatal warning, continues anyway
- Happens if PostgreSQL not running yet
- DB will be created fresh on first deploy

### Deploy approval stuck
- Check: https://github.com/ddotsmedia/ddotsmedia.com/deployments
- Manually dismiss timeout → re-run workflow

### Health check fails after deploy
```bash
# SSH to VPS and check logs
ssh root@187.127.185.239
docker logs --tail 50 ddotsmedia-web

# Check database connection
docker exec ddotsmedia-db pg_isready -U ddots_app -d ddotsmedia

# Check .env.prod is readable
cat /opt/ddotsmedia/.env.prod | head -5
```

### Disk space low (< 15GB)
```bash
# Check usage
ssh root@187.127.185.239
df -h /opt/ddotsmedia

# Free up space
docker system prune -a    # Remove unused Docker images
docker volume prune       # Remove unused volumes
```

## Environment Variables

The VPS runs with `.env.prod` containing:

```env
# Database connection
DATABASE_URL=postgres://ddots_app:PASSWORD@ddotsmedia-db:5432/ddotsmedia

# Secrets (generated by bootstrap)
PAYLOAD_SECRET=<random 32-char hex>
BETTER_AUTH_SECRET=<random 32-char hex>

# Site URLs
NEXT_PUBLIC_SITE_URL=https://ddotsmedia.com
BETTER_AUTH_URL=https://ddotsmedia.com

# Initial admin (change after login)
OWNER_EMAIL=admin@ddotsmedia.com
OWNER_PASSWORD=change-me-after-first-login

# Email (optional - Resend preferred, SMTP fallback)
RESEND_API_KEY=<optional>
RESEND_FROM="Ddotsmedia <noreply@ddotsmedia.com>"
SMTP_HOST=<optional>
SMTP_PORT=587

# Screenshots via ApiFlash (optional)
APIFLASH_ACCESS_KEY=<optional>
```

After first deploy, SSH and update `.env.prod` if needed:
```bash
ssh root@187.127.185.239
nano /opt/ddotsmedia/.env.prod
# Edit RESEND_API_KEY, OWNER_PASSWORD, etc.
# Save and exit: Ctrl+X, Y, Enter

# Restart app to apply changes
docker compose -f docker-compose.prod.yml restart web
```
